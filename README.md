# 地球运动与太阳视运动

基于 Vue、TypeScript 和 Three.js 的地理教学课件，演示地球自转、公转、昼夜变化、四季及太阳视运动，支持离线单文件导出。

## 开发与打包

安装依赖后运行 `npm run dev`，默认打开进阶日晷版。`npm run dev:city` 用于城市版开发，`npm run dev -- --mode standard` 用于标准版开发。

原有命令保留 **23°26′ 度分版**。新增 **23.5° 教材小数版**，角度读数显示一位小数，黄赤交角计算同步采用 23.5°，默认极圈为 66.5°。使用 `npm run dev:decimal` 启动小数日晷版，`npm run dev:standard:decimal`、`npm run dev:city:decimal` 分别启动小数标准版、城市版。

| 版本 | 构建命令 | 导出入口 | 内容 |
| --- | --- | --- | --- |
| 标准版 | `npm run build:standard` | `地球自转与公转-标准版/index.html` | 地球运动主场景、观测数据、公式和副机位 |
| 进阶日晷版 | `npm run build:advanced` | `地球自转与公转-进阶日晷版/index.html` | 主场景与赤道式日晷太阳视运动联动 |
| 进阶城市版 | `npm run build:city` | `地球自转与公转-进阶城市版/index.html` | 主场景与城市太阳视运动联动 |
| 标准版（23.5°） | `npm run build:standard:decimal` | `地球自转与公转-标准版-23.5度版/index.html` | 标准版内容，使用教材小数角度 |
| 进阶日晷版（23.5°） | `npm run build:advanced:decimal` | `地球自转与公转-进阶日晷版-23.5度版/index.html` | 日晷版内容，使用教材小数角度 |
| 进阶城市版（23.5°） | `npm run build:city:decimal` | `地球自转与公转-进阶城市版-23.5度版/index.html` | 城市版内容，使用教材小数角度 |

`build:advanced` 固定导出日晷版；城市版使用单独命令和目录。构建通过 `vite-plugin-singlefile` 内联脚本、样式及纹理，导出后可直接打开对应的 `index.html` 离线使用。

小数版分别使用 `standard-decimal`、`advanced-decimal`、`city-decimal` 模式；对应 `.env.*` 同时指定场景版本和 `VITE_ANGLE_FORMAT=decimal`。原模式明确使用 `dms`，六个输出目录互不覆盖，切回原启动命令即恢复原角度约定。

## 场景与面板

启动时显示页面级加载界面，标准版标题为“地球自转与公转”，进阶版为“地球运动与太阳视运动”。等待天空、地球昼夜、太阳和时区图片加载完成，以及当前版本场景准备就绪后，预上传纹理并完成首帧渲染再展示。加载失败时保留提示和“重新加载”入口。加载期间保留场景布局并锁定交互，避免尺寸变为零；卸载后忽略迟到回调。

角度读数按构建版本统一：原版使用度分格式，例如 +73°12′；小数版使用一位小数，例如 +73.2°。涵盖主场景辅助、观测数据、公式结果、太阳视运动 HUD、城市时钟牌和指北针，正午高度及观测点经纬度也采用对应格式。度分显示的角分四舍五入可正确进位。日晷与城市共用按屏幕像素控制大小的高度角标注，缩放后仍保持可读。

主场景铺满视口。顶部标题栏固定悬浮，提供场景和面板开关；控制、数据、公式及副机位使用 `src/components/FloatingPanel.vue`。界面采用中性墨黑磨砂底色、雾白文字、香槟金主色与浅冰蓝辅助色，左侧按钮统一两列并放大字号。面板支持拖动、折叠、置顶；可调整大小的面板提供角落拖动手柄，也支持聚焦手柄后用方向键调整大小。控制面板默认靠左展开；数据、公式、副机位和图例默认隐藏。数据、公式、副机位打开后从右上方布局，多个面板以 68px 的标题间距错开，手动拖动后保留用户位置。公式初次打开仍为收起状态，副机位默认 460×380，并根据窗口可用空间缩小。顶部按钮只切换面板显隐，保留折叠状态，展开和收起通过面板自己的图标控制。图例固定左下方，控制面板预留图例空间。副机位的视角下拉框位于面板标题栏。

底部浮动控制轴提供总播放按钮，以及公转日期、自转地方太阳时、黄赤交角三条控制轨。点击分至日按钮可定位对应日期；地方太阳时可通过滑块调整，也可点击与刻度对齐的 6:00、12:00、18:00 固定时刻按钮，暂停自转并定位。原版倾角以 1′ 为步长，可从 0° 调整至 23°26′；小数版以 0.1° 为步长，可从 0° 调整至 23.5°，均可一键恢复各版默认值。暂停后仍可手动调节对应滑块。宽屏三轨并排，中屏两排，小屏三排；所有控制均保留，不出现控制轴滚动条。面板与太阳视运动数据区随控制轴高度留出空间。

进阶版左侧为地球运动，右侧为太阳视运动。拖动中间分隔条可调整两侧宽度，聚焦分隔条后也可使用方向键；小屏幕仍保持左右排列，不切换为上下两行。太阳视运动窗口可以从顶部面板开关。

主场景使用 NASA Deep Star Maps 的本地 8K 全天星图（8192×4096），以深黑底色、克制的星光和新的银河朝向展示。太阳视运动环境雾已移除。太阳视运动改用海陆风组件的程序化天空：白昼蓝天、薄云、晨昏暖光及夜空星点，均由当前太阳高度、方位及地方太阳时驱动，暂停后不会另行计时，无需联网图片。地球增加海洋高光和随光照方向变化的大气边缘。

赤道使用红线，南北回归线和南北极圈使用虚线。晨昏线贴近地表，以冰蓝晨线、琥珀昏线和细线柔光区分入昼与入夜；纬线昼弧用金色、夜弧用蓝色强调，分别独立开关，两者均包含 0° 赤道。关闭普通纬线仍可显示昼弧或夜弧，边界随太阳相对方向同步更新；关闭弧段强调后，赤道恢复红色。黄赤交角用黄道、赤道参考射线与角度弧展示，标注大小随相机调整。副机位的南、北极俯视使用正交投影，并按面板短边留白，保留完整赤道外圈；其他副机位使用透视投影。

在“显示图层”中独立打开“正午太阳高度”，地球上会显示当前正午子午线及每隔 10° 的纬度标签，太阳直射点另标出 90°。右侧同时打开读数面板，按 10° 纬度间隔对照南、北半球的正午高度，并单独显示直射纬度和直射点高度。点击面板里的春分、夏至、秋分、冬至按钮可切换二分二至日期；点击“近看正午子午线”可将镜头移近，便于对照地球刻度与读数。图层、直射点及面板数值随日期和黄赤交角同步更新，关闭开关或关闭面板会一并收起该图层。

正午高度采用 `H = 90° − |纬度 − 太阳直射纬度|`。表中比较的是各纬度各自地方正午的高度，不是同一时刻全球各地的即时高度；直射点正午高度为 90°，负值表示正午太阳仍在地平线下，0° 表示太阳中心位于地平线上。读数格式与当前度分版或小数版一致。

顶部“使用说明”打开加宽的卡片式弹窗，内容按当前版本显示。标准版介绍地球运动、观测点与图层操作；进阶版补充双场景联动、地面观测，并分别展示日晷版或城市版说明。进阶版默认只显示地球主场景，点击顶部“太阳视运动”再打开右侧联动场景；首次加载只等待当前展示的场景及其纹理。

地球中心模式同时平移相机与观察目标，保留用户的缩放、旋转和平移偏移；手动调日期、自动公转及镜头切换共用跟随逻辑。太阳光线默认 5 条，沿竖向排列并保持平行；光线控制区分别提供“太阳光辉 · 覆盖昼半球”和“太阳光晕”的开关与强度调节。光辉采用覆盖地球投影圆面的平行柔光束，延伸至晨昏分界平面，并以柔光层包覆整个昼半球；地球内部和夜半球的光辉被遮除。光晕环绕太阳本体，两者独立控制，夜景底图亮度默认 1。

显示图层与观测点辅助各有全开/全关开关，全关时显示“全关”、部分开启时显示“部分”、全部开启时显示“全开”。自选点使用独立开关，默认锁定；开启后轻点地球选点，选好自动锁定。旋转拖动、右键、长按与双指操作不会修改观测点。

进阶版标题栏在“太阳视运动”右侧提供“观测点视角”开关。开启后，镜头用约 6.2 秒依次靠近地球、下降到观测点、抬头看向太阳；完成后默认按当地高度角与方位角追踪太阳。拖动后切为站在原地自由环视，可水平转向、抬头和低头；点击“看向太阳”恢复追踪。罗盘读取实际镜头朝向，提示区区分太阳在当前视野内、在地平线上方但位于视野外以及位于地平线下方。地面视角采用水平地面和昼夜天空，太阳的视角位置由同一份太阳数据决定，避免主场景夸大的球体大小和日地距离带来视差。该视角将日轮角直径教学放大到 3°，并在提示中标明；放大不改变太阳中心高度、方位或日出日落的计算。八方位罗盘显示北、东北、东、东南、南、西南、西、西北及对应 0°–315° 角度，上方表示当前镜头朝向；太阳在天顶时，镜头保留方位参考。飞行期间暂时暂停演示，结束后恢复原播放组合；关闭后分段升空并返回先前视角。控制面板在进入时暂时隐藏，退出恢复原状态；副机位继续观察完整地球。

显示图层下提供独立的“国际日界线”和“理论时区划分”开关，沿地球自转同步显示。时区纹理为本地透明 SVG，来自本地地球时区课件的 24 个理论 15° 分区，标明中时区、东西时区；不将它表述为现行行政时区。日界线使用该课件的现代教学近似折线，绕过北太平洋及基里巴斯、萨摩亚等区域。资源与出处见 `src/assets/image/time-zone-ranges.SOURCES.md`。

## 教学约定

原度分版黄赤交角的默认值与调节上限为 **23°26′**，计算值为 `23 + 26 / 60` 度，滑块保存 0–1406 角分。教材小数版的默认值与调节上限为 **23.5°**，计算值为 `23.5` 度，滑块内部保存 0–1410 角分、每步 6 角分。回归线纬度取当前倾角的正负值，极圈纬度取 ±（90°−当前倾角）：原版默认 ±66°34′，小数版默认 ±66.5°。几何、太阳赤纬、五带及相关说明随调节同步变化，北极圈示例观测点也会跟随新的极圈纬度。版本常量和角度格式集中在 `src/utils/astronomy.ts`。

公转与赤纬共用 `src/utils/earthOrbit.ts`：用四个分至日示例作为四分之一圈的边界，分段推进且跨年连续。赤纬由同一公转角和模型地轴方向计算，满足 `sin δ = sin ε × sin λ☉`（λ☉ 为太阳黄经），不再单独用近似赤纬曲线代替场景几何。调节倾角保留日期、自转相位及播放状态，地方太阳时根据新的太阳相对方向重新求得。

倾角为 0° 时，全年赤纬为 0°，太阳视运动中的季节路径合并为一条；回归线与赤道重合，极圈退至两极。赤道晷面全年处于平行入射状态，白天不形成可读针影；两极的太阳全天沿地平线运行，界面使用地平线临界提示。

演示控制区在“只公转、不自转”时自动显示高亮说明：地方太阳时读数会倒退，公转日期继续向前推进；这是独立停转演示产生的相对运动。恢复自转或暂停公转后，说明自动收起。

演示控制支持分别启停自转、公转，底部总播放按钮可全部暂停，再次点击时恢复暂停前的自转、公转组合。时间滑块只调整自转，日期滑块只调整公转；停转后仍可手动调整。停止自转时，地球相对恒星的朝向不变，公转仍会改变太阳相对方向，此时地方太阳时读数反向变化，公转日期继续向前推进。地方太阳时由太阳时角定义，读数倒退不代表实际时间倒流。

自动演示默认 40×，最高支持 100×。默认自转一圈约 6 秒，最高倍速约 2.4 秒；重置也恢复到 40×。

公转额外加速默认 60x，可独立调整为 1–120x。在默认自动演示速度 40x 下，公转一圈约 37 秒。此为便于观察四季的演示比例，不额外加快自转；设为 1× 可取消公转额外加速。基础自转与公转使用一年 365 日、相对恒星自转 366 圈的教学近似；倍速表示演示比例。

分至日采用 **2026 年北京时间**的日历日期：春分 3 月 20 日、夏至 6 月 21 日、秋分 9 月 23 日、冬至 12 月 22 日。本课件以整日作为季节锚点，采用圆形示意轨道和分段角速度，不表示精确交节瞬间或天文历表。日期依据 [美国海军天文台 2026 年分至时刻表](https://aa.usno.navy.mil/calculated/seasons?dst=false&submit=Get+Data&tz=1&tz_label=false&tz_sign=1&year=2026)，由表中 UTC+1 换算至北京时间 UTC+8。

界面时间为地方真太阳时，方位角从正北顺时针起算。日出日落、昼长采用太阳中心高度为 0° 的几何模型，未计大气折射与太阳视半径；观测点太阳的教学放大不改变该判据。时差 E 采用真太阳时减平太阳时，UTC 为模型推算值。计算符号与日出日落口径参考 [NOAA 太阳位置公式](https://www.gml.noaa.gov/grad/solcalc/solareqns.PDF)；NOAA 实际日出日落采用的 90.833° 天顶距修正在本课件中未启用。

地表昼夜贴图以同一平行太阳方向的 `法线·太阳方向 = 0` 划分，混合仅保留以该边界为中心的像素抗锯齿，不使用跨越多度太阳高度的宽幅过渡。它与晨昏线、昼弧夜弧及昼长数据使用同一太阳中心判据；海洋高光、大气暮光和低太阳高度的明暗变化不改变极昼极夜范围。

在非零倾角的夏至、冬至，晨昏线与 ±（90°−倾角）的极圈相切：夏至北极圈以北为极昼、南极圈以南为极夜，冬至相反，极圈线上存在恰好掠过地平线的临界点。其他日期的极昼极夜边界为 ±（90°−|太阳赤纬|），通常比极圈更靠近极点；极昼不等于全天亮度相同。

## 赤道式日晷

进阶日晷版通过 `src/components/EquatorialSundial.vue` 复用太阳视运动场景，以赤道式日晷取代建筑物，移除广告牌、街道、人行道、路灯及交通灯，保留太阳轨迹、光线、高度角演示、草地和树木。城市版单独保留城市场景。日晷模型接收同一份太阳位置数据，随纬度调整晷面与晷针，夜间及春秋分平行入射时隐藏针影。

太阳视运动默认从正北方向南观察，正面展示北京、上海等北半球地点日晷的朝北刻度面，桌面和平板一致。画面左东右西，北方在前景、南方在远处。日晷倾角和针影保持真实计算，冬季受光面转到下表面，可拖动相机观察。方位标注与太阳计算使用相同的真实坐标；拖动相机后，屏幕上的方位随视角变化。

公式面板默认隐藏，首次显示时为收起状态；顶部“公式”按钮控制显示与隐藏，面板标题栏图标控制展开与收起。

观测点新增厦门（北纬 24.48°、东经 118.08°，城市代表点）。日晷按晷面中心的实际离地高度沿南北方向移动，使晷面中心落在春秋分轨迹平面内（满足 y·sinφ + z·cosφ = 0），从侧面也能看出对齐关系。接近两极时，共面位置会超出场地，此时限制底座位置，保留真实倾角的平行展示。切换城市时同步避开底座周围的树木。

太阳视运动默认显示可收起的紫色平行示意：春秋分轨迹所在平面与晷面平行。橙色的局部入射光线使用同一太阳方向，在春秋分白天止于迎光盘缘，不作为针影绘在盘面上。春秋分说明明确区分“晷面上无可读针影”和“地面上的影子仍可能存在”；日晷移位只改变展示位置，不改变真实太阳方向、晷面倾角或双面针影计算。

太阳标记、光线、高度角扇形和照明共用同一太阳方向，天顶时可准确显示 90°。针影按实际盘缘裁剪，取消盘内的橙色影尖。联动窗口的数据区显示当前受光面，并在当地冬半年、春秋分前后和夜间说明换面或无法读数的原因。

日晷几何依据：[华盛顿大学太阳几何课程](https://courses.washington.edu/arch3431/lectures/L9.pdf)（晷针平行地轴，晷面平行赤道面）。

春秋分掠射说明参考：[日晷制作者的原理图解](https://www.sundials.eu/funzionano/funzionanoENU.html)（春秋分太阳光与晷面平行，无法正常读数）。
