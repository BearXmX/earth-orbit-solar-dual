# earth-orbit-solar-dual
地球公转自转与太阳视运动

演示控制区在“只公转、不自转”时自动显示高亮说明：地方太阳时读数会倒退，实际时间仍向前推进。恢复自转或暂停公转后，说明自动收起。

演示控制支持分别启停自转、公转，顶部按钮可全部开始或全部暂停。时间滑块只调整自转，日期滑块只调整公转；停转后仍可手动调整。停止自转时，地球相对恒星的朝向不变，公转仍会改变太阳相对方向，此时地方太阳时读数反向变化，公转日期继续向前推进。地方太阳时由太阳时角定义，读数倒退不代表实际时间倒流。

自动演示默认 40x（原为 10x），最高支持 100x（原为 20x）。默认自转一圈约 6 秒，最高倍速约 2.4 秒；重置也恢复到 40x。

公转额外加速默认 60x，可独立调整为 1–120x。在默认自动演示速度 40x 下，公转一圈约 37 秒。此为便于观察四季的演示比例，不额外加快自转；设为 1x 可恢复原时间比例。

进阶版的太阳视运动联动使用新组件 `src/components/EquatorialSundial.vue`，复用原 `sun.vue` 的场景，以赤道式日晷取代建筑物，并移除广告牌、街道、人行道、路灯和交通灯。原有天空、太阳路径、光线、高度角演示、草地、树木、数据浮层和布局保持不变。日晷模型接收同一份太阳位置数据，随纬度调整晷面与晷针，夜间及春秋分平行入射时隐藏针影。

太阳视运动默认从正北方向南观察，正面展示北京、上海等北半球地点日晷的朝北刻度面，桌面和平板一致。画面左东右西，北方在前景、南方在远处。日晷倾角和针影保持真实计算，冬季受光面转到下表面，可拖动相机观察。方位标注与太阳计算使用相同的真实坐标；拖动相机后，屏幕上的方位随视角变化。

公式面板默认收起，可通过顶部“打开公式面板”按钮展开。

太阳标记、光线、高度角扇形和照明共用同一太阳方向，天顶时可准确显示 90°。针影按实际盘缘裁剪，取消盘内的橙色影尖。联动窗口的数据区显示当前受光面，并在当地冬半年、春秋分前后和夜间说明换面或无法读数的原因。

日晷几何依据：[华盛顿大学太阳几何课程](https://courses.washington.edu/arch3431/lectures/L9.pdf)（晷针平行地轴，晷面平行赤道面）。

验证：`npm test`、`npm run type-check`、`npm run build:standard`、`npm run build:advanced`。
